# `02-trace` — student template repo (source)

This folder is the **source** for the GitHub *template repository*
`<instructor-org>/02-trace-template` (public, "Template repository" enabled).

The **dso576-apps** web app provisions each student their own copy named
`02-trace-<usc-id>` from that template (`studentRepoName` in
`web/src/lib/core/github.ts`; the prefix `02-trace` is the `cw_repos.kind`).

task stubs) here. See [`../../README.md`](../../README.md) for the full app
connection.
